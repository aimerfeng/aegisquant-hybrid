# 盈利策略测试包

这个文件夹包含了一个可以在模拟A股数据上实现约20%盈利的策略和对应的测试数据。

## 文件说明

- `a_stock_data.csv` - 手工创建的模拟A股数据（约200个交易日）
- `a_stock_data_generated.csv` - 脚本生成的模拟A股数据（约250个交易日）
- `a_stock_data_generated_ohlc.csv` - OHLC格式的数据（包含开高低收）
- `profitable_ma_strategy.json` - 优化过的双均线策略配置
- `profitable_ma_strategy.py` - Python版本的策略

## 使用方法

1. 在AegisQuant中点击"加载数据"，选择 `a_stock_data_generated.csv`
2. 点击"加载策略"，选择 `profitable_ma_strategy.json` 或 `.py` 文件
3. 点击"开始回测"运行回测
4. 使用回放控制面板查看回测过程
5. 勾选图表上的均线选项（MA5、MA10等）查看指标叠加显示
6. 使用绘图工具在图表上画趋势线、水平线等

## 策略说明

该策略使用优化过的双均线交叉系统：
- 短期均线：8日
- 长期均线：21日
- 买入条件：短期均线上穿长期均线（金叉）
- 卖出条件：短期均线下穿长期均线（死叉）
- 止损：3%
- 止盈：8%

## 预期收益

在提供的测试数据上：
- 手工数据：预期收益约15-25%
- 生成数据：预期收益约20-30%（数据本身涨幅约85%，策略可捕捉部分趋势）

## 回测回放功能

1. 加载数据后，使用回放控制面板的播放/暂停按钮
2. 使用单步前进/后退按钮逐根K线查看
3. 使用时间滑块快速跳转到任意位置
4. 观察状态面板中的账户信息变化

## 绘图功能

1. 在图表工具栏选择绘图工具（趋势线、水平线、垂直线）
2. 在图表上点击并拖动绘制
3. 右键点击绘图对象可删除
4. 点击"清除绘图"按钮清除所有绘图
